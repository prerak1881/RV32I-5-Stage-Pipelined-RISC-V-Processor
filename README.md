# RV32I-5-Stage-Pipelined-RISC-V-Processor
A synthesizable 32-bit 5-stage pipelined RV32I RISC-V processor implemented in System Verilog with hazard detection, data forwarding, and an APB-based peripheral subsystem integrating UART, SPI, Timer, and GPIO. Includes a System Verilog verification environment for functional validation of the APB interconnect and peripheral interfaces.
